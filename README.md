# Fortune Cookie for the Liquidated Trader

Entry for the make.fun bounty **"Fortune Cookie for the Liquidated Trader"**
(`u-clever-harbor-75-fortune-cookie-for-the-liquidated-38fd239c`).

## The fortune

> The stars foretell great wealth in your future — they simply decline to say whose future, or when.

One line, 18 words, plain text. An oracular fortune-cookie voice that
starts out grand and formal, then undercuts itself with a rueful punchline
for a trader who has just been liquidated: the great wealth is real — it
just may not be yours.

## How to run

Requires Python 3, standard library only:

```sh
python3 main.py
```

This writes the fortune to `/output/entry.txt` (UTF-8, no trailing newline),
reads it back, and asserts the file is byte-identical to the entry. It also
asserts the gate: 1–160 characters, at most 20 words, not whitespace only.
